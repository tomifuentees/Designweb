# Capturas y beautifiers

Para READMEs, docs y OG: una captura del producto o del código, con un fondo de la paleta. Cambiá el tema default (muchos nacen violetas). No ‘embellezcas’ una UI genérica para disimularla.

Hay **5 recursos** en este grupo. El catálogo completo está en [`recursos.json`](./recursos.json).

## shots.so (beautify)

`shots-beauty` — [https://shots.so/](https://shots.so/)

**Licencia:** Herramienta (tu captura es tuya).

**Cuándo usarlo.** Una captura de producto o de un componente, con fondo de la paleta, sombra o grano contenidos, para un README, un OG o una doc.

**Cuándo no.** Para disfrazar una UI genérica de ‘beauty shot’.

El mismo producto que en mockups. Acá, el valor es el frame y el fondo, no un device.

## ray.so

`ray-so` — [https://ray.so/](https://ray.so/)

**Licencia:** Herramienta de Vercel (tu snippet es tuyo).

**Cuándo usarlo.** Una captura de código para un artículo o un OG, con un tema que no sea el default violeta si podés evitarlo.

**Cuándo no.** Como única imagen de una landing de producto (no es el producto).

Muy usado en Twitter/X de devs. Cambiá el padding y el tema.

## Carbon

`carbon` — [https://carbon.now.sh/](https://carbon.now.sh/)

**Licencia:** MIT (open source).

**Cuándo usarlo.** Capturas de código autoalojables o con más control que ray.so.

**Cuándo no.** El tema default de Carbon también se reconoce; ajustalo.

Repo carbon-app/carbon. Clásico, sigue vigente.

## snappify

`snappify` — [https://snappify.com/](https://snappify.com/)

**Licencia:** Freemium / pago según plan.

**Cuándo usarlo.** Anotaciones, several frames, presentaciones de código o de UI más producidas.

**Cuándo no.** Si Carbon o shots alcanzan. No hace falta un plan pago para un README.

Tiene templates de mesh: no caigas en el violeta de la plantilla.

## Screenzy

`screenzy` — [https://screenzy.io/](https://screenzy.io/)

**Licencia:** Herramienta; confirmá términos.

**Cuándo usarlo.** Beautify rápido de una captura, con fondos y devices simples.

**Cuándo no.** Si el resultado se ve idéntico a todas las otras Screenzy del timeline.

Alternativa ligera a shots.so.

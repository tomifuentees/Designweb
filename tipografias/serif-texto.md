# Serif de texto

9 familias en esta categoría. Catálogo armado en noviembre 2026 para el repo de diseño frontend. Solo se incluyen datos verificados (links oficiales que resolvieron, o —en el caso de Sharp Type— la URL canónica de la foundry, que respondió 429 por un challenge de bot, no 404).

Una serif de texto no es un titular agrandado. Hace falta buen cuerpo, itálica de verdad, y —si se puede— tamaño óptico (Source Serif 4, Newsreader, Literata). Estas familias sirven para blogs, periodismo, docs de producto, marcas culturales y cualquier sitio donde se lea de verdad.

Si el proyecto puede pagar foundry, Tiempos Text es una referencia. Si no, Newsreader o Source Serif 4 rinden muy por encima de Merriweather/Playfair como cuerpo automático.

## 1. EB Garamond

- **Foundry:** Georg Duffner / Ocodo / Google Fonts
- **Licencia:** Gratis. SIL Open Font License, Google Fonts.
- **Link oficial:** https://fonts.google.com/specimen/EB+Garamond
- **Estilo / personalidad:** Garamond de código abierto, de mucho oficio histórico. Ideal para editorial, cultura, vino, estudio jurídico o cualquier marca que quiera tradición sin Times.
- **Mejor uso:** Editorial, Lujo
- **Pesos / ejes:** Varios pesos con cursivas (el eje llega a ExtraBold en la ficha actual).
- **Variable:** Sí
- **Pareja recomendada:** Source Sans 3 o Suisse Int'l

Snippet de import:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=EB+Garamond:ital,wght@0,400..800;1,400..800&display=swap" rel="stylesheet">
/* font-family: "EB Garamond", sans-serif; */
```

## 6. Newsreader

- **Estilo / personalidad:** Serif de prensa digital: cómoda en cuerpo, con una itálica muy usable para enfatizar una palabra en un titular (tendencia 2026 de 'playful italics').

- **Pesos / ejes:** Variable, con opsz, pesos de ExtraLight a ExtraBold y cursivas.

## 7. Sentient

- **Foundry:** Indian Type Foundry / Fontshare
- **Licencia:** Gratis. ITF Free Font License (FFL) 2.0: uso comercial gratis, sin modificar ni redistribuir el archivo.
- **Link oficial:** https://www.fontshare.com/fonts/sentient
- **Estilo / personalidad:** Serif de texto contemporánea del catálogo Fontshare, más rara que Lora o Libre Baskerville. Buena para cuerpos que no quieran parecer 'Google Fonts de siempre'.
- **Mejor uso:** Editorial, Landing, Lujo
- **Pesos / ejes:** Familia Fontshare con varios pesos y cursivas.
- **Variable:** Sí
- **Pareja recomendada:** General Sans o Switzer

Snippet de import:

```html
<link href="https://api.fontshare.com/v2/css?f[]=sentient@400,500,700&display=swap" rel="stylesheet">
/* font-family: "Sentient", sans-serif; */
/* Preferí autohospedar los archivos oficiales. La API de Fontshare no garantiza uptime.
   La licencia FFL no permite subsetear ni convertir el archivo. */
```

## 8. Source Serif 4

- **Foundry:** Adobe / Google Fonts
- **Licencia:** Gratis. SIL Open Font License. Variable, con tamaños ópticos. Es la serif abierta de Adobe, compañera de Source Sans 3.
- **Link oficial:** https://fonts.google.com/specimen/Source+Serif+4
- **Estilo / personalidad:** Serif de lectura de muy buen dibujo, con eje óptico. Ideal para blogs, docs, help centers y sitios de contenido largo que no pueden pagar Tiempos.
- **Mejor uso:** Editorial, SaaS, Dashboard / UI
- **Pesos / ejes:** Variable, con opsz y cursivas; de ExtraLight a Black.
- **Variable:** Sí
- **Pareja recomendada:** Source Sans 3, Public Sans o Cabinet Grotesk

Snippet de import:

<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>

## 9. Tiempos Text

- **Foundry:** Klim Type Foundry
- **Diseño:** Kris Sowersby
- **Licencia:** Comercial. Licencia perpetua Klim, pago único.
- **Precio aproximado:** Desde 60 USD el primer estilo (Klim).
- **Link oficial:** https://klim.co.nz/fonts/tiempos-text/
- **Estilo / personalidad:** Serif de lectura contemporánea, par de Tiempos Headline. Pensada para pantallas y para papel. Una de las mejores opciones de cuerpo cuando el proyecto puede pagar foundry.
- **Mejor uso:** Editorial, SaaS, Lujo
- **Pesos / ejes:** Familia de texto con cursivas y varios pesos.
- **Variable:** No
- **Pareja recomendada:** Tiempos Headline o Söhne

Snippet de import:

```html
/* Comprá la licencia web en la foundry y autohospedá el WOFF2 oficial. */
@font-face {
  font-family: "Tiempos Text";
  src: url("/fonts/tiempos-text-regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
```

# Combinaciones titular + cuerpo

Más de veinte parejas que funcionan en web y producto, armadas a partir de sistemas de foundry, recomendaciones de Typewolf, guías de 2025-2026 y usos reales detectados. La lógica de 2026 es estable: **una cara para expresar, otra para aguantar la lectura**. Contrastá el rol (display vs. texto), no el clima (no pelees una fashion serif con una geométrica infantil).

Cómo usarla: elegí primero el tipo de proyecto, después la pareja. Si el presupuesto no alcanza para la comercial, hay un plan B gratis debajo de casi todas.

---

## 1. Clash Display + Satoshi

- **Por qué funciona:** Las dos salen de Fontshare, comparten un aire geométrico moderno y se licencian igual (FFL). Clash lleva el hero; Satoshi resuelve UI, botones y párrafos sin pelearle el protagonismo.
- **Para qué:** Landing de SaaS, startup, producto digital con ambición. Es la pareja gratis más citada de este ciclo para consumer SaaS.
- **Plan B:** Clash Grotesk + Satoshi, un poco menos gritona.

## 2. Cabinet Grotesk + DM Sans

- **Por qué funciona:** Cabinet pone el carácter (la R, la g) en el título; DM Sans, diseñada por Colophon, sostiene el cuerpo con una geometría tranquila. El contraste es de personalidad, no de época.
- **Para qué:** Rebrand de SaaS, sitio de agencia chica, marketing site que quiere que pregunten "qué fuente es".
- **Plan B:** Cabinet Grotesk + Source Serif 4 si el producto tiene blog largo.

## 3. Fraunces + Geist

- **Por qué funciona:** Fraunces aporta calor, optical size y el eje WONK (lo "humano"); Geist aporta una UI nítida. Es el esquema serif expresiva + sans quieta que definen las tendencias 2026, sin caer en Playfair + Inter.
- **Para qué:** Landing de marca, D2C, estudio, SaaS con voz editorial.
- **Cuidado:** Geist ya se lee "IA / Vercel". Si el producto no es un devtool, reemplazala por Figtree, Onest o Manrope.

## 4. Fraunces + Manrope (o Karla)

- **Por qué funciona:** Misma lógica que la anterior, con una sans más cálida y menos "devtools". Karla aparece en pairings libres de 2026 (Fraunces + Karla) como grotesca amable de cuerpo.
- **Para qué:** D2C, wellness, educación, marcas cercanas que igual quieren oficio.
- **Gratis:** las dos.

## 5. Instrument Serif + Instrument Sans

- **Por qué funciona:** Están diseñadas para convivir (Fuenzalida / Egstad). El serif, sobre todo en itálica, da el gesto editorial; el sans tiene eje de ancho para títulos compactos y UI.
- **Para qué:** Landing fashion-tech, media, producto con pretensión cultural.
- **Cuidado:** En r/web_design (julio 2026) ya marcan Instrument Serif como cliché. Usala si el resto del sistema no parece "otra startup editorial". Alternativa: Newsreader + Instrument Sans.

## 6. Söhne + Tiempos Headline / Tiempos Text

- **Por qué funciona:** Sistema Klim: la grotesca contemporánea más citada en Typewolf 2025 con la serif periodística de la misma foundry. Oficio parejo, sin pelea de estilos.
- **Para qué:** SaaS premium, media, fintech, marcas que pueden pagar foundry.
- **Plan B:** Founders Grotesk + Newsreader, o General Sans + Source Serif 4.

## 7. Söhne + Signifier

- **Por qué funciona:** Misma foundry, más tensión: Signifier es afilada y cultural; Söhne, neutra. El titular se siente caro, el cuerpo no estorba. Stripe y otros productos tech ya demostraron que Söhne aguanta un sistema entero; Signifier le suma voz.
- **Para qué:** Lujo contemporáneo, cultura, landing de estudio, producto "quiet luxury".
- **Plan B:** Untitled Sans + Signifier, todavía más anónimo en la UI.

## 8. Neue Montreal + Editorial New

- **Por qué funciona:** El sistema Pangram más usado: grotesca canadiense contemporánea + serif de revista de lujo. Las dos tienen el mismo dibujo "de agencia 2020s", muy coherente en un brand book.
- **Para qué:** Landing premium, hospitality, moda, SaaS con presupuesto de marca.
- **Plan B:** Switzer + Boska (Fontshare, misma idea, costo cero).
- **Variante:** Neue Montreal + Editorial Old, cuando New ya se siente de template; Old es la versión erosionada, más interesante en 2026.

## 9. Monument Grotesk + Reckless

- **Por qué funciona:** Dos caras con carácter, de foundries distintas (Dinamo y Displaay), que Typewolf registró una y otra vez entre 2023 y 2025. Reckless pone la voz editorial; Monument, la estructura.
- **Para qué:** Identidad de estudio, cultura, producto design-led.
- **Plan B:** Bricolage Grotesque + Reckless no entra en presupuesto: Bricolage + Newsreader.

## 10. Roobert + Reckless

- **Por qué funciona:** Misma foundry (Displaay). Roobert cubre proporcional, semimono y mono; Reckless cubre el momento revista. Un solo proveedor, un sistema completo.
- **Para qué:** Devtools con voz, media, productos que mezclan UI y storytelling.
- **Plan B:** Space Grotesk + Space Mono, o Geist + Geist Mono si se acepta el look Vercel.

## 11. Geist + Geist Mono

- **Por qué funciona:** Sistema de Vercel, pensado para la web, con los mismos huesos en sans y mono. Coherente, rápido de implementar, impecable en un dashboard.
- **Para qué:** Devtools, IA, documentación, producto developer-first.
- **Cuidado:** En 2026 es *el* stack de las landings de AI. Si MaatWork está diseñando un SaaS que no es de infraestructura, mejor Mona Sans + JetBrains Mono o IBM Plex.

## 12. Mona Sans + Hubot Sans (y un mono)

- **Por qué funciona:** El sistema de GitHub: Mona para UI y texto, Hubot (más geométrica, con ancho variable) para momentos de marca, más JetBrains Mono o Plex Mono para código. Un solo origen OFL, ejes de width de verdad.
- **Para qué:** Producto dev, docs, open source, SaaS técnico.
- **En uso:** github.com.

## 13. IBM Plex Sans + IBM Plex Serif + IBM Plex Mono

- **Por qué funciona:** Superfamilia abierta, diseñada para convivir. El sabor es "empresa sólida", no "startup de template". Muy útil cuando un cliente PyME quiere verse formal sin pagar Suisse o Söhne.
- **Para qué:** Enterprise, fintech, salud, gobierno, consultoras, productos B2B.
- **En uso:** ibm.com; el mono aparece en Hugging Face, Sanity, WorkOS.

## 14. Bricolage Grotesque + Newsreader

- **Por qué funciona:** Bricolage trae trampas de tinta, optical size, ancho y grade; Newsreader es una serif de prensa digital con itálicas excelentes (la tendencia de enfatizar *una* palabra del titular). Las dos son OFL y de mucho oficio.
- **Para qué:** Editorial, marcas de contenido, SaaS con blog, landings que quieren carácter sin foundry paga.
- **Variante:** Bricolage + Fraunces es más display todavía; reservala para el hero.

## 15. Syne + Manrope

- **Por qué funciona:** Syne es la sans "rara" que las listas de 2026 recomiendan cuando no se quiere serif; Manrope aguanta el cuerpo con formas abiertas. Contraste de rareza vs. claridad.
- **Para qué:** Agencia, portfolio, startup creativa, landing de producto de consumo.
- **Plan B:** Syne + Onest, un cuerpo todavía más quieto.

## 16. Canela + Graphik

- **Por qué funciona:** Clásico de Commercial Type: serif de lujo + grotesca de producto. Graphik ya estuvo en todos lados (The New Yorker, Basecamp, Todoist), pero junto a Canela sigue siendo un sistema de moda y lifestyle muy creíble.
- **Para qué:** Belleza, moda, hospitality, landing de lujo.
- **Plan B:** Boska + Switzer, o Fraunces + Graphik no entra: Fraunces + DM Sans.

## 17. Feature + Druk

- **Por qué funciona:** Es la pareja que sugiere Typewolf para Feature. Feature trae tamaños ópticos de revista (nació en T Magazine); Druk pone el cartel condensado. Máximo contraste de rol.
- **Para qué:** Editorial de moda, campañas, un hero de una línea, cultural.
- **Cuidado:** Druk en un párrafo es ilegible. Una línea, grande, con aire.

## 18. GT Alpina + GT America

- **Por qué funciona:** Superfamilias de Grilli que cubren serif cálida (con ópticos) y sans norteamericana (con anchos y construcciones). Un solo licenciamiento resuelve marca, UI y editorial.
- **Para qué:** Identidad completa de producto o de medio, cuando hay presupuesto de foundry.
- **Plan B:** Newsreader + GT America no entra: Newsreader + Plus Jakarta Sans.

## 19. TWK Lausanne + Editorial New (o Canela)

- **Por qué funciona:** Lausanne fue la tipografía más vista en Typewolf en 2024 y aparece en Asana y Typeform: es una sans "internacional" un poco más fashion que una grotesca pura. Una serif de lujo le suma voz en el titular, o al revés (Lausanne en UI, Editorial en el hero).
- **Para qué:** SaaS global, marketing sites, marcas que quieren parecer europeas / pulidas.
- **Plan B:** Switzer + Editorial no entra: Switzer + Boska.

## 20. Public Sans + Source Serif 4

- **Por qué funciona:** Dos abiertas, de mucho oficio, pensadas para lectura en pantalla. Public Sans viene del USWDS (confianza cívica); Source Serif 4 trae optical size de Adobe. Nada de pose; todo de claridad.
- **Para qué:** Sector público, salud, educación, legal, trámites, productos que tienen que inspirar confianza institucional.
- **Accesibilidad:** si el público lo pide, Atkinson Hyperlegible en la UI y Source Serif 4 en el artículo.

## 21. Atkinson Hyperlegible + Source Serif 4

- **Por qué funciona:** Atkinson maximiza la distinción de caracteres (I / l / 1, O / 0); Source Serif sostiene la lectura larga. Es una pareja ética antes que estética, y aun así se ve profesional.
- **Para qué:** Salud, edtech, gobierno, adultos mayores, cualquier producto donde equivocar un carácter no es una opción.
- **Variante:** Atkinson + Lexend (si todo el sistema es de baja visión; Lexend no tiene ficha propia en este catálogo, está en Google Fonts).

## 22. Cal Sans + Geist o Inter

- **Por qué funciona:** Cal Sans (la cara de Cal.com) da un titular geométrico minimalista; una sans de UI probada sostiene formularios y tablas. El carácter está en el logo y en el H1, no en cada label.
- **Para qué:** SaaS de productividad, scheduling, herramientas internas.
- **Cuidado:** no dejes Inter solo en el hero.

## 23. Space Grotesk + Space Mono

- **Por qué funciona:** Hermanas de un mismo dibujo (Karsten / Colophon). La proporcional sirve de UI y de título; la mono, de label y de gesto retro-tech. Muy coherente en marcas "construidas, no decoradas".
- **Para qué:** Devtools, hardware, agencias digitales, landings técnicas.
- **Variante:** Space Grotesk + Newsreader, si hace falta calor editorial.

## 24. Departure Mono + Inter (o Instrument Serif)

- **Por qué funciona:** Un pairing documentado en guías de 2026: la mono pixel pone el gesto humano/máquina; Inter (o un serif fino) hace de texto. El contraste es extremo, por eso funciona en dosis chicas.
- **Para qué:** Sitios de autor, estudios, lanzamientos, no un dashboard de un banco.
- **Cuidado:** Departure no es una mono de código a 12px.

## 25. Obviously + Newsreader (o Tiempos Text)

- **Por qué funciona:** Obviously vive del eje de ancho (de ultra condensada a extendida): es un sistema de titulares por sí sola. Una serif de lectura la ancla para que no se vuelva un poster eterno.
- **Para qué:** Identidad expresiva, campañas, cultura, D2C con motion typography.
- **Plan B:** Unbounded o Syne + Newsreader, las dos OFL.

## 26. Agrandir + Neue Montreal

- **Por qué funciona:** Otra pareja Pangram: Agrandir (muchísimos anchos y recortes de display) + Neue Montreal de texto. Cuidado de no saturar un mismo sitio con tres PP a la vez (Mori + Agrandir + Editorial ya es un look "plantilla de foundry").
- **Para qué:** Brand systems, packaging digital, landings de lanzamiento.
- **Plan B:** Panchang + Satoshi (Fontshare).

## 27. Zodiak + Clash Grotesk (o Satoshi)

- **Por qué funciona:** Serif incisiva + geométrica de la misma casa (Fontshare). Gratis, coherente, mucho menos vista que Playfair + Montserrat, con el mismo rol (titular de contraste + cuerpo moderno).
- **Para qué:** Editorial digital, marcas culturales, landings de producto con voz.
- **Variante:** Boska + Switzer para un lujo un poco más "revista".

## 28. Aeonik + Newsreader

- **Por qué funciona:** Aeonik es una geométrica de foundry muy citada en r/webdesign 2025; Newsreader le pone un cuerpo de prensa que evita que todo el sitio se vea "solo fashion sans".
- **Para qué:** Producto digital premium, estudios, landings B2B con más carácter que Plus Jakarta + Inter.
- **Plan B:** Aspekta o Sora + Newsreader.

---

## Atajos por tipo de proyecto

| Tipo de proyecto | Primera recomendación | Alternativa gratis |
|---|---|---|
| SaaS PyME / landing de producto | Clash Display + Satoshi, o Cabinet Grotesk + DM Sans | Las mismas (ya son gratis) |
| SaaS B2B / formal | Söhne + Tiempos, o IBM Plex completo | IBM Plex o Plus Jakarta Sans + Source Serif 4 |
| Devtools / IA | Mona Sans + JetBrains Mono, o Plex | Evitá Geist si querés diferenciarte |
| Editorial / media | Feature + Graphik, o GT Alpina + GT America | Fraunces + Figtree, o Newsreader + Bricolage |
| Lujo / moda / hospitality | Canela + Graphik, o Signifier + Söhne | Boska + Switzer, o Melodrama + Satoshi |
| Cultura / estudio | Monument Grotesk + Reckless, o Karrik + Newsreader | Bricolage + Newsreader, o Sprat + Apfel Grotezk |
| Gobierno / salud / educación | Public Sans + Source Serif 4 | Atkinson Hyperlegible + Source Serif 4 |
| Dashboard denso | Untitled Sans o Inter *como UI*, con un display aparte en marketing | Figtree, Onest o Geist en la app; nunca el display en una tabla |

Una sola regla final: **mostrá la pareja en el hero y en un párrafo de 150 palabras** antes de enamorarte del specimen.

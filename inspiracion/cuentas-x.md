# Cuentas de X

Solo cuentas cuya existencia se confirmó el 19 de noviembre de 2026 con la API de X (`get_users_by_usernames`). El handle es el que devolvió la API (mayúsculas incluidas cuando aplica; X es case-insensitive). No se inventaron perfiles, y se **descartaron** handles que no eran la persona o el proyecto que parecían: `@sdras` no es Sarah Drasner (es otra cuenta, casi inactiva); `@NandoRojo` no era el ingeniero conocido. Sarah Drasner está en [@sarah_edo](https://x.com/sarah_edo).

[@JoshWComeau](https://x.com/JoshWComeau) existe, pero su bio dice que **la cuenta ya no está activa** y que se fue a Bluesky. Se lista como referencia, no como follow vivo.

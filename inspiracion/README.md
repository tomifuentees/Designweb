# Inspiración

Estante de galerías, sitios de referencia, cuentas de X y newsletters, armado el 19 de noviembre de 2026 (zona America/Argentina/Salta). El objetivo no es un moodboard infinito: es que un agente (o vos, con apuro) abra **un** referente con un porqué, no 40 screenshots de Dribbble, y que ese porqué se pueda cruzar con un estilo de [`../estilos/`](../estilos/README.md).

Hay **22 galerías** con URL verificada, **55 sitios** de referencia agrupados por slug de estilo, **32 cuentas de X** cuya existencia se confirmó con la API, y **8 newsletters**. El índice machine-readable está en [`inspiracion.json`](./inspiracion.json).

## Cómo usar esto (humano o agente)

1. **Elegí primero el estilo** en [`../estilos/README.md`](../estilos/README.md), no la galería. La galería es un cajón; el estilo es el criterio.
2. **Abrí dos o tres sitios de esa ficha**, no una decena. Anotá *qué* vas a robar (el ritmo, un filete, una rareza) y qué no (el logo, la paleta entera, el scroll-jack).
3. **No copies un SOTY de Awwwards en una PyME** si el trabajo pide [`../estilos/expresivo-minimo.md`](../estilos/expresivo-minimo.md). Recent y Awwwards sesgan hacia lo espectacular.
4. **Mobbin, Refero y Page Flows** son para producto (flujos, no landings). Land-book, Lapa y SaaS Landing Page son para marketing.
5. Un sitio vivo puede haber rediseñado hoy. Si el “porqué” ya no está, no lo forces: buscá otro de la misma ficha.

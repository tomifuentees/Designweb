# Designweb

Base de conocimiento de diseño visual para frontend. Sirve para lograr mejores terminaciones y escapar de los diseños genéricos que suele hacer la IA (Inter + gradiente violeta + cards iguales).

Está pensada para dos usos:
- **Referencia humana**: elegir tipografías, estilos y combinaciones con criterio.
- **Contexto para agentes** (Claude Code, Cursor, etc.): los `.json` son machine-readable para que una skill elija con datos reales.

## Contenido

| Carpeta | Qué tiene | Estado |
|---|---|---|

| `paletas/` | Paletas probadas con tokens | ⏳ |
| `componentes/` | Hero, pricing, navbar, cards bien resueltos | ⏳ |

| `inspiracion/` | Sitios y cuentas curadas | ⏳ |
| `skills/` | Skills para agentes que consumen este kit | ⏳ |
